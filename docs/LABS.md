# Laboratory Model

## Terminology

The catalog uses common Russian names plus English names, abbreviations and aliases. Unverified LOINC/FSLI codes remain empty rather than guessed.

## Reference intervals

The report-specific laboratory reference is the primary comparison source. It is distinct from clinical decision limits, population references, user targets and AI interpretation.

## Units

Original values and units are always retained. Canonical conversion only occurs when an analyte-specific deterministic conversion is defined. Numeric reference bounds are converted with the same conversion so the status never compares different unit systems.

Lp(a) mass and molar units are not universally converted.

## Import trust model

CSV/PDF/OCR output is untrusted candidate data. It must be reviewed and explicitly confirmed before persistence. Uploaded document text cannot issue instructions to the application or AI system.
